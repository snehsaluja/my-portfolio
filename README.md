# Sneh Saluja — Portfolio

A static portfolio website. Ready to deploy on Hostinger (or any static hosting).

## Structure

```
├── index.html        ← HTML shell
├── css/
│   └── styles.css    ← Custom styles
├── js/
│   └── app.js        ← Data, rendering & interactions
└── assets/
    └── sneh.PNG      ← Profile photo
```

## Hosting on Hostinger

1. Log in to your Hostinger control panel
2. Go to **File Manager** → `public_html/`
3. Upload `index.html` and the `css/`, `js/`, `assets/` folders
4. Your site is live!
